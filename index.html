    Accepted column names

    Any of these will work as your CSV/spreadsheet header. Case doesn't matter.

    Question (English): Question_EN, Question, Q, Question EN, Q_EN
    Question (Kannada): Question_KN, Q_KN, Kannada, Question KN
    Options: Opt_A_EN / A_EN / Option A / OptA / A — same for B, C, D
    Kannada options: Opt_A_KN / A_KN / Option A KN — same for B, C, D
    Correct: Correct, Answer, Ans, Correct Answer (must be A/B/C/D)
    Explanation: Explanation, Explain, Solution, Sol
    Subject tag: Subject, Topic, Category
    Sub-topic: Sub_Topic, Subtopic, Sub Topic — optional, anything more specific under Subject; leave blank to track the question against the Subject only
    Difficulty: Difficulty, Level, Diff (a number 1–5; blank/invalid is left unrated)
    Image URL (English/default): Image, Image_URL, Diagram, Graph_URL
    Image URL (Kannada-only override): Image_KN, Image_URL_KN, Diagram_KN — leave blank to reuse the English image for Kannada too

    If your file uses different names, the studio will show a mapping dialog after upload.

    "Match the following" questions

    Don't try to line up columns with spaces — that breaks on screen and in print. Instead, put each matched pair on its own line in the question text, with the two lists separated by a |:

    Match List I with List II and select the correct code:
List I | List II
A. Article 356 | 1. President's Rule
B. Article 360 | 2. Financial Emergency

    Any run of consecutive lines containing a "|" is shown as a real two-column table wherever the question appears (exam screen, Practice Mode, review, PDF). Lines without a "|" render as normal text. Options and the Correct answer work exactly as usual — e.g. options like "A-1, B-2".
